# Setup 

These classes are written in JavaScript and NodeJs is required to run these in your terminal. Tools suggested are noted below:
Windows:
Powershell/Windows Terminal/Git Bash
NodeJs

Linux/MacOS
Terminal
NodeJs

Altering these files can be done with a text editor of your choice, such as Windows notepad. Enhanced capability is available from dedicated editors such as Atom, notepad++ or VS Code. 

## Running tests

Tests can be run from the command line in Windows/Mac/Linux.

First: Clone the repository
Second: Install the dependencies with npm install
Third: Tests can be run on any platform with npm test

## Additional changes and manually testing output
There is an instantiation of an example customer in the Customer.js file. This file can be run by entering the below in the terminal and pressing enter:

node Customer.js
