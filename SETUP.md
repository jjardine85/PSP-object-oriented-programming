# Setup 

These classes are written in JavaScript and NodeJs is required to run these in your terminal. Tools suggested are noted below:
Windows:
Powershell/Windows Terminal/Git Bash

Linux/MacOS
Terminal

Altering these files can be done with a text editor of your choice, such as Windows notepad. Enhanced capability is available from dedicated editors such as Atom, notepad++ or VS Code. 

## 1 Check tools

```text
git --version
```

macOS/Linux:
```text
node --version
node Account.js
```

Windows:
```text
node --version
node Account.js
```
